# Banner HTML 1254x120 - Penca Ovación

Adaptación horizontal del banner interactivo de Penca Ovación para la medida 1254x120.

## Archivos

- `index.html`: estructura del anuncio horizontal con branding, quiz, tiendas y logos.
- `styles.css`: layout fijo 1254x120, cancha animada, estados y estilos de la pieza.
- `script.js`: banco editable de preguntas provistas, rotación de 3 preguntas por ronda y banderas por país cuando corresponde.

## Uso

Abrí `1254×120/index.html` en un navegador o servilo con un servidor estático desde la carpeta `1254×120`:

```bash
cd 1254×120
python3 -m http.server 8000
```

Luego visitá `http://localhost:8000`.
