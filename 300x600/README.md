# Banner HTML 300x600 - Penca Antel Ovación

Banner estático e interactivo inspirado en la landing de Penca Antel Ovación para promocionar una penca del Mundial 2026.

## Archivos

- `index.html`: estructura del anuncio de 300x600 con preguntas interactivas.
- `styles.css`: dirección visual, layout fijo, animaciones y estados responsive/accesibles.
- `script.js`: banco editable de preguntas, rotación de 3 preguntas por ronda, banderitas para opciones de países, resumen final y reinicio.

## Uso

Abrí `300x600/index.html` en un navegador o servilo con un servidor estático desde la carpeta `300x600`:

```bash
cd 300x600
python3 -m http.server 8000
```

Luego visitá `http://localhost:8000`.
